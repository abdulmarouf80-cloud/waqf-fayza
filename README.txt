وقف القرآن الكريم — فايزة محجوب بابكر

الملف الرئيسي: index.html

هذه نسخة أولية قابلة للنشر وليست منشورة على الإنترنت بعد.
لفتحها: افتح index.html في متصفح حديث مع اتصال بالإنترنت.
يتم تحميل النص القرآني والتلاوات من Quran.com API؛ لذلك يتطلب العرض اتصالاً بالإنترنت.

للنشر المجاني عبر GitHub Pages:
1. أنشئ حساباً في GitHub ثم مستودعاً عاماً جديداً.
2. ارفع index.html إلى المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم الفرع main والمجلد /root ثم Save.
5. بعد اكتمال النشر سيظهر رابط الموقع المجاني في صفحة Pages.

ملاحظة: اختبر النص والتلاوات بعد النشر. واجهة Quran.com قد تتغير، وقد يتطلب الربط تحديثاً مستقبلاً.
